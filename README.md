# ENSAM Meknès African Network

A production-ready Next.js (App Router) website for the English class project: **ENSAM Meknès African Network**.

## Deploy on Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. In Vercel, click **Add New → Project** and import the repository.
3. Keep the default build settings (Framework: Next.js) and click **Deploy**.

Vercel will automatically build and publish the site.
